## 看图的要点

- **横轴 u（化学势，带隙中点 = 0）**，上横轴是 3D 等效载流子浓度（2D 按层厚 t 归一）
- **蓝实线** = BT2 × DPT-τ（S8.1）
- **橙点** = AMSET ADP only（S8.4）
- **灰虚线** = 文献数字化（Fig.5 σ / Fig.7 PF / Fig.S3 κe / Fig.S4 Seebeck）
- **粉底** = AMSET 掺杂网格覆盖范围；**灰底** = 深能带区（离带边 >0.5 eV，刚带近似失效）
- 下排是带边放大（±1 eV）
