## 关键观察

1. **对全部 6 组（3 材料 × 电子/空穴），文献值都落在我们 DPT 与 AMSET-ADP 之间**，
   且更靠近 DPT（DPT 高 12–30%，AMSET-ADP 低 22–44%）。

2. **两种方法差异的物理来源**：
   - **DPT**：Bardeen-Shockley 解析式 μ = eℏ³C_2D/(k_BT·m*·m_d·E1²)，
     用带边标量质量 + 标量形变势，是文献采用的口径
   - **AMSET-ADP**：直接用完整 q 依赖的散射矩阵元与 2D 屏蔽核做布里渊区积分，
     包含了 DPT 忽略的各向异性与多谷贡献 → 通常更低

3. **对文献复现的结论**：文献值高于我们 AMSET-ADP，说明文献确实用的是 DPT 简式
   （而非全积分 AMSET），与我们判断一致；其数值比我们 DPT 低 12–30%，
   主要来自 m* 定义差异（见 `01_对照表/mstar_窗口扫描.csv`）。

4. **作图说明**：柱 = x/y 对角分量的均值；误差棒 = x–y 差；
   数字为对应均值（我们的值已直接标注在柱顶）。
