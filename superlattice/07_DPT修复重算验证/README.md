## 二、[0071] 2D 表头 m\* 改用 m_d（**SS 受影响**）

### 修复内容

2D 表头（isotropic 汇总）的 m\* 原来取"方向分解最轻两支"的几何平均。
当带边不强制面内各向同性时（矩形胞 Γ、**SS/LS 的 Y–Γ 带边**），最轻两支都在轻轴上
→ 表头 m\* 是**轻轴质量**而非 m_d，导致表头 μ ∝ 1/m\*² 虚高。

**修复**：这类体系改用 `by_direction` 的 **m_d = √(m_x·m_y)**（与 [0025] 的 3D 同口径）。
六方 K/Γ、四方 Γ、手填质量不变（MoS2、CrS2/CrSe2 不受影响）。

**说明**：
- CrS2/CrSe2 是六方 K/Γ 带边，面内各向同性 → 表头 m\* 本来就等于 m_d → **不变**
- SS 是矩形胞、Y–Γ 带边、面内各向异性 → 修复后**表头 μ 大幅下降**（回到物理正确值）
- **by_direction（逐方向）值全部不变** → 所有基于逐方向的分析（双口径表、三线对比、综合报告）不受影响
