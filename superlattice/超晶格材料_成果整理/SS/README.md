# SS（CrS2/CrSe2 短周期横向超晶格）

## 结构
- 12 原子（4 Cr + 4 S + 4 Se），横向超晶格
- a = 10.819 Å（x），b = 3.125 Å（y），c = 20 Å
- 来源：归档 S1 CONTCAR（PBE，external pressure −0.02 kB）

## 计算链
| 步骤 | 来源 |
|---|---|
| S1–S6 | **归档复用**（INCAR 逐字节一致，S3 网格 12×42×3 合规） |
| S6_elastic | ⚠️ 归档 S6 缺弹性模量标记，本次**重算** |
| S7_deform（10 帧）+ S7.1_read | 新算 |
| S8.2_dpt / S8.1_bt2 / S8.4_amset2d / S8.3_cmp | 新算 |

- PBE 带隙 0.8185 eV（文献 0.816）
- S3 = 12×42×3

## 与文献偏差
- E1: +2.4%/−2.4%，C_2D: ~0% ✅
- m*: −8.9%〜−10.5%
- μ: +18%〜+28%（文献口径 −3.0%〜+9.1%）
- **空穴 y 方向原偏差 −0.5%（m* 与 E1 的误差恰好抵消）**

## 注意
SS 的 m* 对 k 网格不敏感（旧版 15×15 与新版 12×42×3 几乎相同），
说明 SS 的 m* 与文献差异**不是网格问题**，而是 m* 定义（q→0 vs 有限窗口）不同。
