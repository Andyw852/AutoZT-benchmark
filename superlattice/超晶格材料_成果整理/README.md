## 关键结论（详见 Word 报告）

- 弹性 C_2D、形变势 E1、有效质量 m*、弛豫时间 τ、迁移率 μ、Seebeck S 与文献一致（1–10%）
- 电导率 σ 有非恒定残差（0.74–1.87），已排除代码/口径/元胞/带隙/DFT 设置/价带 K–Γ，最可能是文献数字化误差
- 晶格热导 κ_L 与 ZT 未算（需 kl 链）
