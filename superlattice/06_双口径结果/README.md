# 双口径结果：我们的 q→0 口径 vs 文献的有限窗口口径

> 目的：把有效质量（m\*）的两种提取口径**各自完整重算一遍**，各自得到一套
> μ / τ / σ / PF / κe，便于与文献同口径对比，同时保留我们自己更严格的口径。

---

## 一、两种口径的定义

| | **口径 A（我们，q→0 外推）** | **口径 B（文献，有限窗口抛物线）** |
|---|---|---|
| m\* 提取 | 拟合 E = c₁q² + c₂q⁴，取 **q→0 极限** | 带边附近取一段 k，**直接抛物线拟合** E = cq² |
| 物理含义 | 真正的带边曲率（数学极限） | 含非抛物性的"实用有效质量" |
| 数值 | 较轻 | 较重 5–10% |
| 对应文献 | — | 文献 Table I 的口径 |

**口径 B 的 m\* 数值来源**：`../01_对照表/mstar_窗口扫描.csv`
（CrS2/CrSe2 用抛物线 2×r_nn；SS 用抛物线 3×r_nn 分方向）

---

## 二、公式与哪些量会变

### 2.1 DPT 公式族

$$\mu_\alpha = \frac{e\hbar^3 C_{2D,\alpha}}{k_B T\, m^*_\alpha\, m_d\, E_{1,\alpha}^2},\qquad
\tau_\alpha = \frac{\mu_\alpha m^*_\alpha}{e} = \frac{\hbar^3 C_{2D,\alpha}}{k_B T\, m_d\, E_{1,\alpha}^2}$$

$$\sigma_\alpha = \left(\frac{\sigma}{\tau}\right)^{\rm BoltzTraP2}_{\alpha} \cdot \tau_\alpha,
\qquad PF_\alpha = S_\alpha^2\sigma_\alpha,
\qquad \kappa_{e,\alpha} = L\,\sigma_\alpha T$$

### 2.2 两种口径下各量的变化

| 量 | 是否随口径变 | 关系 |
|---|---|---|
| **m\*** | ✅ 变 | 口径 B 更重 |
| **m_d** = √(m\*_x m\*_y) | ✅ 变 | 同上 |
| **μ_α** | ✅ 变 | μ ∝ 1/(m\*_α m_d) → **变 (m_A m_dA)/(m_B mdB) 倍** |
| **τ_α** | ✅ 变 | τ ∝ 1/m_d → **变 m_dA/m_dB 倍** |
| **σ_α** | ✅ 变 | σ ∝ τ → 与 τ 同倍 |
| **PF_α** | ✅ 变 | PF = S²σ → 与 σ 同倍 |
| **κ_e,α** | ✅ 变 | κe = LσT → 与 σ 同倍 |
| **S_α** | ❌ **不变** | Seebeck 只取决于能带结构/DOS，与 m\* 口径无关 |
| **n(μ)** | ❌ 不变 | 同上 |
| **E1, C_2D** | ❌ 不变 | 直接由 DFT 给出，两口径相同 |

## 六、结论

1. **口径差异只影响 m\* → μ/τ/σ/PF/κe**，不影响 S、n、E1、C_2D
2. **口径 B（文献口径）下，我们的 DPT 迁移率与文献一致**（中位 −1.1%）
3. **口径 A（我们的 q→0）仍是更严格的定义**，保留作为主结果
4. 两套结果都完整保存，便于后续按需引用
5. LS 完成后按同一流程补入两口径

## 七、复现

```python
# 300K 参数与 μ
mu_A = e*hbar**3*C2D / (kB*T*mA*m0*mdA*m0*(E1*e)**2)
tau_A = mu_A*mA*m0/e
# 口径B：把 mA→mB、mdA→mdB 代回同式
sigma_B = sigma_A * (mdA/mdB)
PF_B = S**2 * sigma_B
kappa_B = L * sigma_B * T
```

数据表：`params_300K.csv`（两口径）、`transport_600K.csv`（两口径）、`对比_*.csv`
